# ⚡ FRIDAY Gaming Bridge (Android Helper APK)
### 🎮 Tarika B: Zero-ADB Native Free Fire In-Game Co-Pilot

Ye app **Accessibility Service (`dispatchGesture`)** use karta hai, jisse Friday AI bina kisi **Wi-Fi ADB, Wireless Pairing, ya Laptop** ke direct Free Fire screen par real touch (Auto-Drag Headshots, Sit-up Gloo Wall, Auto-Heal, AFK Safezone Running) execute kar sakta hai!

---

## 🚀 3-Step Simple Setup:

### 1️⃣ Step 1: App Install Karo
* APK file phone me install karo (`FridayGamingBridge.apk`).

### 2️⃣ Step 2: Accessibility Permission Allow Karo
* Phone ki **Settings** -> **Accessibility** (या Installed Services) me jao.
* **FRIDAY Gaming Bridge** ko dhund kar **ON** kardo.
*(Optional: Floating Window / Overlay permission bhi allow karein taaki game ke upar floating HUD dikhe).*

### 3️⃣ Step 3: Render URL Dalkar Connect Karo
* App open karo.
* Apna Render Server URL daalo (Jaise `https://mera-ai.onrender.com`).
* **🚀 CONNECT TO FRIDAY** button par click karo.
* Status **🟢 Active & Ready for Free Fire** ho jayega!
